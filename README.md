# cursor-tidd

Cursor IDE 向けの**チケット駆動開発 (Ticket-Driven Development)** テンプレート。

既存のタスクやドキュメントを構造化されたチケットに整理し、作業コンテキストを保持しながら開発を進めるためのフレームワークです。

## TiDD とは

TiDD (Ticket-Driven Development) は、すべての作業をチケットとして管理する開発スタイルです。cursor-tidd では以下の特徴を持ちます：

- **1チケット = 1ファイル**: `_tickets/<NNN>-<slug>.ticket.md` にすべてを集約
- **作業ログが主役**: 調査結果・手順・判明した事実を時系列で蓄積し、日を跨いでもコンテキストを失わない
- **AIフレンドリー**: Cursor のスラッシュコマンドと連携し、既存のドキュメントやタスクからチケットを生成
- **軽量**: 最小限のルールで最大限の効果。プロジェクトに合わせて柔軟にカスタマイズ可能

## 導入方法

自分のプロジェクトに以下のディレクトリをコピーしてください：

```
.cursor/
├── rule/
│   └── tidd.mdc              # 基本ルール（alwaysApply: true）
├── commands/
│   ├── ticket.md              # /ticket コマンド
│   └── implement.md           # /implement コマンド
├── template/
│   └── slug.ticket.md         # チケットテンプレート
└── steering/
    └── steering.md            # プロジェクトメモリ（テンプレート）

_tickets/                      # チケット格納ディレクトリ（空で作成）
```

### チーム利用の場合

`.cursor/` と `_tickets/` をそのまま Git にコミットしてチーム全体で共有します。

### 個人利用の場合（既存リポジトリに後付け）

チームの `.gitignore` を汚さずに TiDD ファイルを Git 管理対象外にするには、`.git/info/exclude` を使います。このファイルはローカル専用で、リモートには共有されません。

`.git/info/exclude` に以下を追記してください：

```
.cursor/
_tickets/
```

これにより、TiDD 関連のファイルは自分のローカル環境にだけ存在し、チームのリポジトリには一切影響しません。

> **`.git/info/exclude` vs `.gitignore`**
>
> | | `.gitignore` | `.git/info/exclude` |
> |---|---|---|
> | 共有範囲 | リポジトリ全体（コミットされる） | ローカルのみ |
> | 用途 | チーム共通の除外ルール | 個人的な除外ルール |
> | TiDD での使い分け | チーム利用時 | 個人利用時 |

### セットアップ後

1. `.cursor/steering/steering.md` を自分のプロジェクトに合わせて編集します（プロジェクト概要・技術スタック・制約条件）
2. 既存のチケットやドキュメント（Notion、GitHub Issues等）を読み込み、`/ticket` で整理し、`/implement` で実装を進めます

## ワークフロー

```
1. 既存のチケットやドキュメント（Notion等）を読み込む
   ↓
2. /ticket でチケットに整理＆タスク分解
   ↓
3. /implement を確認しながら実装
   ↓
4. 重要な決定は steering.md に記録
```

## コマンド一覧

| コマンド | 用途 | タイミング |
|----------|------|-----------|
| `/ticket` | 既存タスクやドキュメントをチケットに整理・タスク分解 | タスクが決まったら |
| `/implement` | タスク実装とチケット更新 | 実装開始時 |

## チケットの構成

```markdown
# タイトル

**Status**: draft | **Created**: YYYY-MM-DD

---

## 背景と目的        ← なぜこの作業が必要か
## 方針              ← どう解決するか
## タスク一覧        ← 何をやるか（実行可能なタスク）
## 作業ログ          ← 時系列の記録
## 参考URL           ← 末尾
```

## ドキュメントの役割分担

| ファイル | 役割 | 内容 |
|---------|------|------|
| `README.md` | プロジェクト紹介 | 外部向けの概要、セットアップ手順 |
| `.cursor/steering/steering.md` | 意思決定の記録 | なぜこうなったか、選択の背景と理由 |
| `_tickets/<slug>.ticket.md` | チケット単位の作業記録 | 背景・方針・タスク・作業ログ・参考URL |

## カスタマイズ

### プロジェクト固有のルールを追加

`.cursor/rule/tidd.mdc` の末尾にプロジェクト固有のルール（破壊的コマンドの制限など）を追加できます。

### チケットテンプレートの拡張

`.cursor/template/slug.ticket.md` を編集して、プロジェクトに必要なセクションを追加できます。
