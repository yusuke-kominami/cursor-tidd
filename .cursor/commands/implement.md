# タスク実装

タスクを実装し、完了後にチケットファイルを更新します。

## 実装前

- [ ] 対象チケットの `{番号}-ticket.md` を開き、タスクと方針を確認
- [ ] 詳細なコンテキストが必要な場合は `{番号}-worklog.md` を参照
- [ ] 前提タスクが完了していることを確認
- [ ] `.cursor/steering/steering.md` で技術スタックを確認

## 実装中

1. 小さく始める（最小構成で動作確認）
2. 必要ならテスト・エラーハンドリングを追加
3. 作業中に判明したことは `{番号}-worklog.md` に追記

## 実装後

### 1. タスクの状態を更新
`{番号}-ticket.md` のタスク一覧を更新する。
```
⬜ 未着手 → ✅ 完了
```

### 2. 作業ログに追記
`{番号}-worklog.md` に追記する。
```markdown
### YYYY-MM-DD - タスクX: [タスク名]
- 実装した内容の概要
- 判断・決定したこと
```

### 3. 全タスク完了時
```
Status: in-progress → done
```

### 4. ドキュメント更新の検討
- **steering.md**: 技術スタックの追加・変更、アーキテクチャの変更があった場合
- **README.md**: セットアップ手順や使い方が変わった場合
